# Data Dictionary

| Column | Data Type | Description |
|---------|-----------|-------------|
| Campaign_ID | Text | Unique campaign identifier |
| Campaign_Type | Text | Type of marketing campaign |
| Target_Audience | Text | Target customer group |
| Duration | Number | Campaign duration |
| Channel_Used | Text | Marketing platform/channel |
| Impressions | Number | Number of ad views |
| Clicks | Number | Number of ad clicks |
| Leads | Number | Potential customers generated |
| Conversions | Number | Successful conversions |
| Revenue | Number | Revenue generated |
| Acquisition_Cost | Number | Cost to acquire customers |
| ROI | Decimal | Return on Investment |
| Language | Text | Campaign language |
| Engagement_Score | Decimal | User engagement score |
| Customer_Segment | Text | Customer category |
| Date | Date | Campaign date |
